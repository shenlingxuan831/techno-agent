科研成果商业化 BP — 话术与表格模板（团队定稿）

纲领与字数：bp_research_commercialization_outline.html
模块 id / writer_hint / needs_chart：config/bp_transform_outline_registry.json

下文为撰写时可复制的结构、话术与表格骨架；与纲领冲突时以纲领与注册表为准。

0.1 保密级别、版本号、更新日期

保密级别（封面顶部居中）
- 公开 / 内部 / 机密 / 绝密（与访问权限一致；机密、绝密需协议与审批说明）。

版本号（保密等级下一行）
- 格式：V主版本.次版本.修订号（如 V1.2.1）。
- 主版本+1：整体架构、核心分析模型、一级标题逻辑重大调整。
- 次版本+1：二级/三级标题内容边界、字数限制、图表数量优化且不改整体框架。
- 修订号+1：叙述结构、排版、数据来源优先级说明微调或错别字。

更新日期（版本号下一行）
- 格式：YYYY-MM-DD

阅读对象：政府评审 / 投资机构 / 合作企业 —— 生成前须识别，再决定章节取舍。

章节 政府评审 投资机构 合作企业

规则：必选必出；「可选」是否纳入由用户/上下文明示。

0.3 数据标注与来源（≤200 字摘要区可用）

  • 数据通过页脚引用来源注明。
  • 优先级：内部实测 > 第三方报告 > 学术文献 > 行业估算（附录列来源清单）。
  • 正文用语：【事实】/【推断】/【待验证】。

一、执行摘要（800～1200 字；总-分-总；无整节大图）

须覆盖：项目一句话介绍；市场机会；核心优势；商业模式；财务要点；风险与结论。

子块 固定话术/边界
一句话介绍 「[成果名称] 通过 [核心技术] 解决 [痛点]，面向 [场景] 提供 [产品形态]。」≤50 字
市场机会 目标行业；[X]亿元规模、CAGR；TAM/SAM/SOM 若可知必写
核心优势 相比 [竞品]；量化对比；≤3 点
商业模式 盈利方式 1+2；定价；渠道；合作方类型
财务要点 本轮融资、用途、约第 N 年营收、回本周期
风险与结论 1 个关键风险 + 措施 + 可行/谨慎/不可行

二、项目背景与概述

  • 2.1 研发背景：来源、周期、团队（话术：「本项目源于[来源]…历时[X]年…」）。
  • 2.2 成果现状：TRL、里程碑表（研发→验证→落地）、当前进展一句话。
  • 2.3 商业化定位：赛道、切入场景、价值主张（「通过[技术]实现[效果]」）。
  • 2.4 发展愿景：短/中/长期量化目标 + 里程碑表；可配路线图、TRL 曲线。

三、核心技术与科研成果（章合计 ≤2000 字）

小节 要点 必用/推荐
3.1 技术原理 通俗逻辑；A→B→C 推荐原理图
3.2 创新点 ×3 突破+痛点+不可替代 无
3.3 技术参数 与行标/竞品对比 参数对比表
3.4 验证数据 实验室/小试/中试 验证数据汇总表；未测写「待测」
3.5 知识产权 类型/号/状态/权属 IP 清单表
3.6 技术壁垒 专利/工艺/人才 与 6.4 错开侧重

四、市场分析（章合计 ≤2000 字）

  • 4.1：PEST + 产业链；4.2：TAM/SAM/SOM 表+增速；4.3：客户画像表；4.4：痛点；4.5：波特五力+竞品表（可选雷达）；4.6：钻石模型+落地条件。

（市场规模表字段、用户画像表字段、竞品表字段等长表—按团队已定稿 Word 或协作文档照抄即可；逻辑与字段名与纲领一致。）

五、商业化落地方案

  • 5.1.1～5.1.4：产品介绍、2～3 场景、TRL、边界；整组 5.1 控 600～800 字。
  • 5.2 商业模式：以图为主（利益相关者 / 场景再现 / 虚实 / 营销形态四选一逻辑）。
  • 5.3.1～5.3.5：盈利模式—篇首概括图；渠道与回报、收费、成本、价值依据、回本测算。
  • 5.4 产业布局：人才=项目+资源；主/子业务图标化。
  • 5.5.1：实施路径（研发→推广），可百分比；流程图。

六、运营团队与组织规划（章合计 ≤800）

  • 6.1 核心团队（履历表、数据化业绩）；6.2 顾问；6.3 资源优势（组图+页尾可复现数据源）；6.4 专利布局（侧重组织）；6.5 产品+用户双视角竞品。

七、财务规划

  • 7.1～7.6：成本、收入（可弱化）、利润、现金流、盈亏平衡、融资；必用年度成本表、3～5 年营收利润表、现金流表、融资用途表；推荐趋势图与敏感性图。

八、风险分析与应对

  • 8.1～8.4 各一类风险；8.5 风险矩阵（类型、概率、影响、等级、措施）。

九、结论与展望

  • 9.1 可行性；9.2 核心价值；9.3 展望（字数见纲领表）。

十、附录 A～F

  • A 实验/测试数据
  • B 知识产权证书
  • C 履历与资质
  • D 市场调研与行业报告
  • E 意向书与协议模板
  • F 财务测算明细与假设

附录：用户需提供信息清单

必须：成果名称/领域/用途；原理+3 创新点+3～5 参数；验证数据摘要；IP 数量与状态；1～2 名核心人选。
可选：中试与竞品参数、目标行业与场景、资金区间、痛点与合作意向等。
