## 0.1 保密级别、版本号、更新日期

**保密级别**（封面顶部居中）  
- 公开 / 内部 / 机密 / 绝密（与访问权限一致；机密、绝密需协议与审批说明）。

**版本号**（保密等级下一行）  
- 格式：`V主版本.次版本.修订号`（如 V1.2.1）。  
- **主版本+1**：整体架构、核心分析模型、一级标题逻辑重大调整。  
- **次版本+1**：二级/三级标题内容边界、字数限制、图表数量优化且不改整体框架。  
- **修订号+1**：叙述结构、排版、数据来源优先级说明微调或错别字。

**更新日期**（版本号下一行）

## 0.3 数据标注与来源（≤200 字摘要区可用）

- 数据通过**页脚引用来源**注明。  
- **优先级**：内部实测 > 第三方报告 > 学术文献 > 行业估算（附录列来源清单）。  
- 正文用语：`【事实】/【推断】/【待验证】`。

## 一、执行摘要（800～1200 字；总-分-总；无整节大图）

**须覆盖**：项目一句话介绍；市场机会；核心优势；商业模式；财务要点；风险与结论。

| 子块 | 固定话术/边界 |
|------|----------------|
| 一句话介绍 | 「[成果名称] 通过 [核心技术] 解决 [痛点]，面向 [场景] 提供 [产品形态]。」≤50 字 |
| 市场机会 | 目标行业；[X]亿元规模、CAGR；TAM/SAM/SOM 若可知必写 |
| 核心优势 | 相比 [竞品]；量化对比；≤3 点 |
| 商业模式 | 盈利方式 1+2；定价；渠道；合作方类型 |
| 财务要点 | 本轮融资、用途、约第 N 年营收、回本周期 |
| 风险与结论 | 1 个关键风险 + 措施 + 可行/谨慎/不可行 |

---

## 二、项目背景与概述

- **2.1 研发背景**：来源、周期、团队（话术：「本项目源于[来源]…历时[X]年…」）。  
- **2.2 成果现状**：TRL、里程碑表（研发→验证→落地）、当前进展一句话。  
- **2.3 商业化定位**：赛道、切入场景、价值主张（「通过[技术]实现[效果]」）。  
- **2.4 发展愿景**：短/中/长期量化目标 + 里程碑表；可配路线图、TRL 曲线。

---

## 三、核心技术与科研成果（章合计 ≤2000 字）

| 小节 | 要点 | 必用/推荐 |
|------|------|-----------|
| 3.1 技术原理 | 通俗逻辑；A→B→C | 推荐原理图 |
| 3.2 创新点 ×3 | 突破+痛点+不可替代 | 无 |
| 3.3 技术参数 | 与行标/竞品对比 | **参数对比表** |
| 3.4 验证数据 | 实验室/小试/中试 | **验证数据汇总表**；未测写「待测」 |
| 3.5 知识产权 | 类型/号/状态/权属 | **IP 清单表** |
| 3.6 技术壁垒 | 专利/工艺/人才 | 与 6.4 错开侧重 |

## 五、商业化落地方案

- **5.1.1～5.1.4**：产品介绍、2～3 场景、TRL、边界；**整组 5.1 控 600～800 字**。  
- **5.2 商业模式**：**以图为主**（利益相关者 / 场景再现 / 虚实 / 营销形态四选一逻辑）。  
- **5.3.1～5.3.5**：盈利模式—篇首概括图；渠道与回报、收费、成本、价值依据、回本测算。  
- **5.4 产业布局**：人才=项目+资源；主/子业务图标化。  
- **5.5.1**：实施路径（研发→推广），可百分比；流程图。
